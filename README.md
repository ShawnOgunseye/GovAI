# aigov.ogunseye.com

The built site for **How to Govern AI**, by Shawn Ogunseye. Published with
[Quarto](https://quarto.org) and served by GitHub Pages from `docs/` on `main`.

The book's source is kept elsewhere; this repository holds the rendered output.

The first edition, *Governing AI: Leading Responsible Innovation* (v1.5.2), is
archived at [/v1/](https://aigov.ogunseye.com/v1/) and remains citable at
[doi.org/10.5281/zenodo.18407349](https://doi.org/10.5281/zenodo.18407349).

Second edition: CC BY-NC 4.0. First edition: CC BY-NC-ND 4.0.

Corrections and broken links are welcome in
[Issues](https://github.com/shawnogunseye/GovAI/issues).
